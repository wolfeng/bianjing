# 汴京城地图 · Web 第一版开发文档

> 目标：先上线 **Web 版**，再用同一套坐标/图例做原生 App。  
> 技术栈：Vite + MapLibre GL JS · 数据：GeoJSON / CSV · 打包日：2026-11-05

---

## 1. 快速开始（Antigravity）

```bash
cd bianjing_web
npm install
npm run dev
```

浏览器打开终端提示的本地地址（默认 `http://localhost:5173`）。

生产构建：

```bash
npm run build    # 输出 dist/
npm run preview  # 预览构建结果
```

## 3. 底图与坐标系

| 模式 | 数据文件 | 底图 | 说明 |
|---|---|---|---|
| 默认 | `*_wgs84.geojson` | OpenStreetMap（WGS84） | 开源可跑，国际一致 |
| 勾选「GCJ-02」 | `*_gcj02.geojson` | 仍为 OSM 时会有偏移 | 若换高德/腾讯底图再勾选 |

侧栏有 **使用 GCJ-02** 开关。上线国内若用火星坐标瓦片，保持勾选并替换 `main.js` 里 raster tiles URL。

**不要**把 GCJ 点画在 OSM 上当精确位置，或把 WGS 点画在高德上。

## 4. 图层

- **城墙 / 苑囿**：外城、里城、宫城（大内）、金明池（面）
- **河渠 / 御街**：汴河、蔡河、五丈河、金水河、御街（线）
- **古地名**：约 508 点，按 `legend.json` 类别着色

点击点可看名称、类别、置信度、冲突提示。

---

## 5. 两套图例

与原生方案同一套 `legend.json`（version 2）：

- **远景**（`zoom < 12.5`）：彩色圆点
- **近景**（`zoom ≥ 12.5`）：类别/专用图标（铁塔、繁塔、州桥等）+ 名称标注

阈值可在 `src/main.js` 的 `isNear()` 里改。`legend.json` 的 `farWhenLatitudeDeltaGreaterThan` 是原生 MapKit 用的跨度阈值，Web 用 zoom 近似。

## 7. 建议下一步

1. 换国内底图（高德/天地图）并默认 GCJ-02

5. 同一 `public/data` 供日后 SwiftUI / 小程序复用
