## 二、文献与考古报告

- 《北宋东京开封府城的形制布局》（故宫博物院院刊 PDF）：外城方向 190°，四面墙长，各墙经过的村落，城门、水门的相对位置，里城与宫城的尺寸。
- 丘刚《开封宋城考古述略》：三重城墙的实测数据，新郑门、新曹门瓮城，宫城在龙亭公园一带。
- 丘刚《北宋东京城御街遗址探析》：南薰门、龙津桥、朱雀门、州桥、宣德门；御街叠压在中山路下。
- 《北宋东京城顺天门遗址 2012～2017 年勘探发掘简报》及院方新闻：顺天门中心坐标、瓮城尺寸。
- 州桥遗址（2022 年度全国十大考古新发现）：州桥位置，唐宋时期汴河宽 25～28 米。
- OSGeo 中国《北宋东京城的形制与规模》、印象河南网《南薰门》、百度百科“南薰门”。
- 孟元老《东京梦华录》卷一：城门名称、直门两重与屈曲开门、樊楼、金明池、琼林苑、开封府的位置。

## 四、置信度说明

- anchored：有现存建筑、OSM 实测或考古给出的坐标，误差大致在 50 米以内（外城门按所在墙的长度推算，误差约 100–300 米）。
- estimated：根据文献记载的相对位置或墙上的比例插值得出，误差约 200–800 米。
