# 地名文献核查报告（SEARCH_CHECK）

核查对象：places.csv 全部 512 个地名。本次未修改任何坐标，只给出修正建议。

## 核查方法

1. 全文检索：从维基文库下载《东京梦华录》10卷和《汴京遗迹志》（四库全书本）24卷。每个地名的简体、繁体及别名都逐一在这两部书中检索，同时做异体字归一（如“薫/薰”“徳/德”）。
2. 方位提取：只提取紧跟在地名之后的定位语，即“X，在……”或“X〈在……〉”这类句式。从中识别“某门外/里”“某地之东西南北”“某地前/后/侧”等方位，再与我方坐标对照：
   - 门内外：区分里城门与外城门，判断我方点是否在相应城墙内外，并要求距该门不超过 2.5–3 km；
   - 方位：我方点相对参照地标的方向必须一致，距离不超过 2.5 km；
   - 紧邻（前/后/侧）：距离不超过 600 m。
3. 网络检索：对自动判为冲突或偏差的条目，以及版本有疑义的条目，再做网络检索并人工复核（识典古籍、文林社、维基文库《宋会要辑稿》、故宫博物院《北宋东京开封府城的形制布局》、开封党史方志网、中国历史地理论丛等），排除了误判。
4. 校准点：坐标来自考古报告或现存地标的点（城门、铁塔、繁塔、州桥、大相国寺等），引用 SOURCES.md 中的出处，判为“一致”。

> 局限：没有对 512 个地名逐一做网络检索，只对重点条目做了网络检索。《东京梦华录》卷二、卷三多是“自某处南去……街北某某”这类沿街叙述，程序无法稳定解析，所以“有记载但无可比方位”的条目很多（257 个），需要人工阅读才能进一步判定。《宋东京考》《宋会要》（方域部分除外）尚未全文检索。

### 景德寺（寺院）

### 迎祥池（园林池苑）

## 轻微偏差

- **巴楼寺（另处1）**：《汴京遗迹志》卷十：“巴樓寺〈在城西金水河南〉”；我方点在城西、金水河以南，方向相符，但距金水河较远…… 建议：可向北靠近金水河南岸（出处：https://zh.wikisource.org/wiki/汴京遺蹟志_(四庫全書本)/卷10）
- **景德寺（另处1）**：同上。“在麗景門外迤東”“在上清宫背”。我方点在旧宋门东1304m、北2430m，方向相符但偏北过远…… 建议：并入“景德寺”，取上清储祥宫北侧位置（出处：https://www.wenlinshe.com/chapter/skqs_shibu/bian-jing-yi-ji-zhi/juan-10.html）
- **金龙四大王庙**：《汴京遗迹志》卷十一：“金龍四大王廟〈在祥符縣治之南汴河北岸州橋之側〉”（明代庙，指明祥符县治）；我方点距州桥731m…… 建议：明代地名，北宋层可移除或靠近州桥北岸（出处：https://zh.wikisource.org/wiki/汴京遺蹟志_(四庫全書本)/卷11）

## 附带发现

- **蔡河水门名称**：《宋史·地理志》作“惠民河上曰普濟，下曰廣利”，与河道流向（自戴楼门入、自陈州门出）矛盾。《宋会要辑稿·方域》南壁门序为“南熏—次东普济—次东宣化（陈州门）”“次西广利—次西安上（戴楼门）”，即普济在东（下水门），广利在西（上水门）；故宫博物院的论文也作“戴楼门东有蔡河上水门（广利水门），陈州门西有蔡河下水门（普济水门）”。本数据集现行命名与此一致，不必修改。
- **开宝寺、上方寺（铁塔）在里城内还是里城外**：《东京梦华录》作“旧封丘门外”，四库本《汴京遗迹志》作“安远门裏”，属版本异文。开封地方史研究认为，北宋里城北墙在今铁塔公园南部，故铁塔在里城外。我方的里城北墙复原线与此一致。
- **法云寺有两个点**：map1 的点远离太学和云骑桥，map2 的点（另处1）与《东京梦华录》“太学东门以南街东法云寺”相符。建议保留后者。
