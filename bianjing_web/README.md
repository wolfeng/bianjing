# 汴京图考 Web 端应用 (Bianjing Web Application)

> **北宋东京城历史地理信息系统 · Web 客户端与 PWA 离线应用**

本项目为「汴京图考」的交互式 Web 端主工程。基于 **Vite + MapLibre GL JS** 构建，原生支持桌面与移动端触控，提供高精度北宋城池与现代天地图的古今时空叠合对照。

---

## 🌟 系统核心能力

1. **🏛️ 双重实证基准锚定**：
   * 严格区分并标明 **北宋官方规制名称** 与 **现存地面文保建筑**；
   * 涵盖开宝寺铁塔、天清寺繁塔、延庆观玉清宫故址、延春阁（龙亭高台基址）、吹台（禹王台）等地面实测基准；
   * 涵盖顺天门（新郑门）、朱雀门、州桥、明德门等经国家现代考古发掘证实的坐标基准。

2. **🗺️ 现代天地图四色底图与古今对照**：
   * 集成国家公共地理信息平台（天地图）CGCS2000 国家坐标系；
   * 支持 **古卷暖色**、**标准矢量**、**卫星影像**、**地形晕渲** 4 大风格一键平滑切换；
   * 现代开封街巷地名注记支持无级透明度调节，实现古今城市肌理的直观穿透。

3. **📱 PWA 渐进式离线支持 & GPS 实地对照**：
   * 完整的 PWA 清单（`manifest.webmanifest`）与 Service Worker 离线缓存；
   * 支持在 iOS Safari / Android Chrome / Edge 等浏览器直接「添加到主屏幕」作为独立 App 运行；
   * 支持高精度 GPS 实时定位，实地探访开封城时可在古今图层上实时显示您当前所处的宋代位置。

4. **🔍 分级图例与智能检索**：
   * **近景/远景自适应呈现**：宏观尺度下以色彩分类圆点清晰展现全城空间格局，微观街区尺度下无缝切换为精美瓦当建筑定制图标；
   * **智能地名联想纠错**：支持分类筛选（城门水门、宫殿官署、寺观祠庙、桥梁河渠、酒楼瓦子）与跨朝代别名索引（如输入“铁塔”直达“开宝寺塔”，“龙亭”直达“延春阁”）。

5. **🔒 密钥分离与安全配置**：
   * 天地图 API 密钥完全解耦，支持 `.env.local` 本地环境变量、URL 参数 `?tk=...` 以及网页端可视化动态配置。

## 🛠️ 本地开发与构建

### 1. 安装依赖
```bash
npm install
```

### 2. 配置天地图 Key
复制配置模板并填入您的天地图浏览器端 Key（可前往 [天地图控制台](https://console.tianditu.gov.cn/api/key) 免费申请）：
```bash
cp .env.example .env.local
```
在 `.env.local` 中配置：
```env
VITE_TIANDITU_KEY=你的天地图Web端Key
```

### 3. 本地开发调试
```bash
npm run dev
```
访问控制台输出的本地服务地址（如 `http://localhost:5173`）。

### 4. 生产打包
```bash
npm run build
```
打包输出目录为 `dist/`，可直接部署至任何静态网站托管服务（GitHub Pages / Vercel / Nginx 等）。
